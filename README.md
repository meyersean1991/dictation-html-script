## What is dictation?

dictation is a small HTML package centered on a local file reference so you can load it quickly and skip elaborate setup. It targets people who want a thin browser UI for dictation-oriented work instead of a full application stack.

If you need a portable, file-backed utility you can open on disk, read as source, and move around easily, this repo is aimed at that use case. The layout stays minimal so access and inspection stay simple.
